## Sucrase

Source: https://github.com/alangpierce/sucrase

Pinned version: `3.35.1`

CodexBarCore vendors a pre-built browser bundle of Sucrase as the resource
`Plugins/sucrase-3.35.1.min.js` and ships it inside
`CodexBar_CodexBarCore.bundle`. It transpiles TypeScript provider plugins inside
the embedded QuickJS engine. This is bundled JavaScript rather than linked
native code, so it carries no symbols — it was missed by an inventory based on
`nm` output and found on 2026-09-03 by auditing the built bundle's resources.

The vendored artifact is generated from the official npm package by
`Scripts/regenerate-sucrase-bundle.sh` in the pinned CodexBar checkout, which
pins the version and requires the output to match a recorded SHA-256. Upstream's
own `LICENSE` file is not vendored with the bundle; the artifact carries this
banner as its license notice:
