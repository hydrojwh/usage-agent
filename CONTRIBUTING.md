# Issues and bug reports

Thank you for helping improve Usage Agents.

## Before opening an issue

- Do not paste tokens, cookies, CLI auth files, raw provider payloads, or account identifiers.
- Include the operating system version and provider CLI version.
- Describe whether the problem affects the menu bar, popover, widget, or Windows taskbar.
- For a missing menu-bar item, do not recommend process killing or Control Center preference edits.

## Code and asset contributions

This repository is a generated public mirror of a private commercial codebase.
Until HydRoMo adopts a contributor license agreement or equivalent commercial
inbound grant, pull requests containing code, assets, translations, or
substantial documentation are not accepted and will not be merged.

Please use an issue to describe the problem and a minimal reproduction without
submitting implementation content. Maintainers may independently implement a
fix in the private canonical repository, run the complete release gates, and
publish it in a later mirror commit.
